# Madrid Tourism Intelligence Dashboard

An exploratory data analytics project built using Google Maps Places API, Python and Power BI to analyze Madrid's tourism ecosystem.

## Project Overview

I wanted to explore the tourism landscape of Madrid using real-world data rather than relying on publicly available datasets.

To do this, I built a custom data collection pipeline using the Google Maps Places API, gathering information about:

* Tourist attractions
* Museums
* Restaurants
* Tapas bars
* Cafés
* Hotels
* Hostels

across several Madrid districts:

* Centro
* Malasaña
* Chueca
* Salamanca
* Lavapiés
* La Latina
* Chamartín
* Retiro

The collected data was then enriched and transformed to generate business-oriented metrics such as popularity scores, tourism density indicators and opportunity rankings.

Finally, the dataset was visualized through an interactive Power BI dashboard.

## Tech Stack

* Python
* Pandas
* NumPy
* Google Maps Places API
* Power BI

## Dataset

The final dataset contains more than 1,300 tourism-related locations within Madrid.

Main attributes:

* Name
* Rating
* Number of reviews
* Price level
* Geographic coordinates
* Tourism category
* District
* Popularity score
* Density metrics

## Key Questions

This project aims to answer questions such as:

* Which areas concentrate the highest tourism activity?
* How does tourism supply vary across districts?
* Which neighborhoods offer the best quality-price balance?
* Are there underserved areas with potential business opportunities?
* What type of tourism dominates each district?

## Dashboard Features

* Executive KPIs
* Geographic heatmap
* Price vs quality analysis
* Tourism category distribution
* Popularity ranking
* Opportunity ranking
* Interactive filtering
